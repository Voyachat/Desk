# Agent Note：设置使用全框架侧边栏视图

Status: implemented

[English](2026-08-19-full-frame-settings-navigation.md) | 中文

## Problem

设置原先以居中卡片形式显示在模糊遮罩上。卡片把较长的设置页面限制在较小的嵌套滚动区域内，压缩可见内容宽度，也让多个持久配置页面之间的导航表现得像临时提示交互的一部分。

## Decision

设置打开时，设置外壳用全框架视图替换应用工作区。固定宽度的侧边栏持有返回控件、「设置」标题和分区导航；内容栏持有本地配置文件操作，并独立滚动当前分区。外壳保留既有的组件本地打开状态和当前分区状态、slot 注册、Escape 处理、进入焦点及对话框无障碍名称。

返回控件继续使用既有 `settings.close` seat，因为分区注册方已经收到同一个关闭回调，且产品中不存在第二种设置退出操作。它的可见文案改为「返回应用」，直接说明目标位置，而不再描述原有卡片交互。

## Alternatives considered

没有保留居中卡片并只扩大尺寸，因为模糊遮罩和脱离工作区的卡片仍会表达临时模态交互。没有把设置移入应用路由，因为 Web 外壳目前通过 slots 组合主要页面，尚无负责这项本地查看状态的路由 owner。没有提供可折叠的设置侧边栏，因为当前分区数量不需要第二种显示模式。

## Consequences

打开设置会保留应用进程和已经挂载的功能 store，但在用户返回或按下 Escape 前，设置会在视觉上替换工作区。各分区获得视口剩余的完整宽度，并共享一个稳定滚动容器。归具体功能所有的设置行、嵌套确认弹窗、首次使用引导步骤和持久化行为保持不变。
