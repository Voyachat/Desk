# Agent Note：包模式 Typert 生成只处理当前包

[English](2026-08-15-package-mode-typert-generation-scope.md) | 中文

状态：已实现

## 问题

tsdown 插件有两种生成模式。工作区模式有意发现并一次输出所有选择加入的贡献者，而包模式是单个包 bundle 的组成部分。如果包模式要求工作区生成器处理每个包，独立包构建就会检查无关工作区包，并可能因为另一个包尚未完成的类型而失败。

## 决策

包模式读取距离 bundle 输出最近的 manifest，并使用该 manifest 的包名和所请求的 face 调用 `WorkspaceTypertGenerator.generate()`。它不调用工作区发现。工作区模式仍是唯一发现所有选择加入贡献者的路径。

## 已考虑的替代方案

我们否决了在包模式保留工作区发现，因为独立构建会继续依赖无关包是否就绪。我们也否决了增加包级忽略列表，因为每个新贡献者都需要中央维护，而且构建仍会检查超出请求范围的包。

## 影响

独立包 bundle 只分析并写入该包的 Typert 产物。生成完整工作区仍需要显式执行工作区模式预处理。tsdown 插件的回归测试包含另一个选择加入的包，并验证包模式只请求正在构建的包。
