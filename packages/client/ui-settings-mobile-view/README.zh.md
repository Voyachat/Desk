# @voyaseek-ai/dsh-client-ui-settings-mobile-view

[English](README.md) | 中文

用于配置带身份验证的只读手机监听器的本机专属**远程查看**设置页。它联合读取 `mobile-view` 用户设置 namespace、`VOYASEEK_MOBILE_VIEW_TOKEN` 的只写凭据元数据，以及 Host 监听器状态接口。本机用户可以启停监听器、选择端口、轮换访问令牌，并复制检测到的局域网地址。新令牌只在创建它的浏览器进程中显示；已保存的凭据原值不会通过读取响应返回。

非回环连接不会注册此页面。启用后只会启动由 [`dsh-mobile-view`](../../host/mobile-view/README.zh.md) 拥有的独立手机监听器；它不会暴露主 Web 服务器、增加写操作或创建公网隧道。

## 模型体验

无。本包只修改浏览器设置和监听器配置，不贡献任何模型可见输入。

#### KV Cache 影响

无；本包既不组装也不发送模型请求。

## 已知限制与暂缓事项

- 地址来自 Host 可见的外部 IPv4 网卡；用户需要选择手机实际可达的地址，并在必要时配置本机防火墙。
- 本包不提供 DNS、TLS、VPN/私有组网成员管理、NAT 穿透或公网隧道。
- 忘记的令牌无法读回，只能重新生成。
