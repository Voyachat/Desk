# Aistaff 语言策略

[English](README.md) | 中文

AI Staff 桌面部署的产品级语言行为规范，完全通过已文档化的 DSH 扩展点实现（包括系统提示词 section 和上下文、设置文档、一个面向模型的工具），从而确保上游 harness 更新可直接合并至本包，无需修改本包任何代码。

该策略由以下三种行为共同构成：

1. **默认输出语言**：一个常驻的系统提示词 section 明确指定回复内容及所有交付物类型（网页、电子表格、文档、演示文稿、媒体）的默认语言。该 section 优先解析用户的 `locale.preference` 设置值；若未配置，则回退至当前行的 `defaultLocale` 配置。
2. **对话自适应**：一个运行时上下文增量（delta）用于报告用户近期输入中检测到的语言——仅当该语言与基线语言不同时才触发。该增量完全基于已记录的用户消息生成，因此恢复会话时将复现相同的响应。
3. **显式语言规则**：模型通过 `language_rule` 工具记录用户指令（例如“此网页保持英文”）。这些规则持久化存储于 `aistaff-language` 设置命名空间中，并在所有尊重该策略的会话运行时上下文中持续渲染，直至被显式移除。

只要宿主设置服务可用，该设置命名空间即完成注册。提示词与工具的贡献则在其对应服务就绪时独立挂载；所有注册行为均遵循所属插件的生命周期，在插件 dispose（资源释放）时一并清理。

## 配置

| 字段 | 含义 |
| --- | --- |
| `defaultLocale` | 当设置文档中未显式声明 `locale.preference` 时，所采用的语言标签。 |

## 模型体验

### 默认输出语言段

#### 模型所见内容

人格设定之后紧接一个系统提示词段。

##### 默认输出语言提示词

```markdown
Default output language: Simplified Chinese (zh). Use Simplified Chinese for all assistant replies and for all user-facing content in every deliverable.
```

#### Token 影响

约 120 个 token，存在于该部署组合的每个会话的每次请求中。

#### KV Cache 影响

用户不修改语言设置时，该段保持稳定，因此系统提示词前缀可跨轮次和会话保留在缓存中。

### 对话语言增量上下文

#### 模型所见内容

基线已经匹配时，常见路径不添加内容。用户输入语言不同时，一个运行时上下文段会指出当前对话语言；已记录规则会追加一个区块。该内容渲染到标准、已记录的运行时上下文快照中。

#### Token 影响

未启用时为零；每个生效的覆盖或已记录规则增加数十个 token。

#### KV Cache 影响

该内容遵循既有运行时上下文快照生命周期，只在语言检测结果或规则存储变化时改变。

## 已知限制与待办事项

- 在绕过 DSH 提示词组装机制的驱动器（如 Claude Agent SDK 运行时、外部 CLI subagent 提供方）下运行的会话，无法应用本策略；覆盖此类场景需先在对应驱动器中引入能力 seam。
- 语言检测依赖确定性脚本与词汇启发式算法；极少数混合文字输入可能无法判定，此时维持上一次选定的语言。
